## 业务规则

U1：淋浴洗浴用品收纳整架及明确便携淋浴篮/袋属于核心范围。浴玩、皂盒组合、泛浴室/台面/厕纸收纳属于相邻研究池，不进入核心商品数分母。

U2：标题明确表达整架主体加附属安装件的组合装，保留 `BUNDLE` 角色，进入单独的核心包装组。只有通过上下文主体证据的限定规则才准入；普通随箱安装件、纯替换件、其他整品混装和仅有 bundle 字样均不因此放行。每个 listing 只计一次，不拆包装件数或分摊销量。
